When a tag
goes quiet.

The short answer

When an RTLS tag is not seen for a while, the honest answer is “last seen at this place, at this time”, not a guess at where it is now. AmIMotion’s AmIHub keeps every position with the time it was seen, so the map shows how old each one is. Tags send when they move and sleep when still, so a quiet tag at rest is normal; a quiet tag that should be moving is a reason to check its battery, mounting or coverage.

Why tags go quiet

  • The tag is still and sleeping, which saves battery.
  • It is somewhere with poor coverage, such as inside a metal cage.
  • The battery is low, which AmIHub reports ahead of time.
  • The tag fell off or was moved to another object.

Freshness is its own measure

How often a tag sends, how long processing takes and how often a screen refreshes are three different things. A precise point can still be too old to act on. Set a freshness target per task.

What the map should show

Old data shown as old. A trolley not seen for an hour should read “last seen 1 h ago, Line-side B”, with no animation suggesting it is live.

Checking quality in a pilot

Count how often tags are found where people expect them, how old positions are when people use them, and how many corrections people make.

Common follow-ups.

What happens if an RTLS tag is not seen for a while?

AmIHub keeps its last position and time, and the map shows “last seen”. It does not guess where the tag is now.

How long do AmIGo batteries last?

1 to 3 years, typical and usage-dependent. Battery level is reported to AmIHub.

Can a tag be moved to another trolley?

Yes. Re-pair it in AmIHub so its history stays with the right object.
