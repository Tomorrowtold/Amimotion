Value before the MES link.

Yes, you can prove the value of RTLS before a live MES connection. Search time, how long carriers wait in each zone and where work piles up all come from location and time alone. AmIMotion pilots often start this way: AmIGo tags on one flow’s trolleys, located down to ±10 cm in 3D, with the job link added as a pilot step before any result is called job-level.

  1. What location shows on its own
  2. What needs the job link
  3. A pilot plan that works

What location shows on its own

  • Where each tagged trolley, bin or tool is, and when it was last seen.
  • Time in each zone, by shift and station.
  • How often people search, and how long finding something takes.

What needs the job link

Which job waits where, and job-level lead times, need the carrier-to-job link. Start it with a simple scan at loading, then connect the MES when the pilot earns it.

A pilot plan that works

  1. Measure search time and walks before tags go on.
  2. Tag one flow’s carriers and agree a few zones.
  3. Add a scan-based job link for part of the pilot.
  4. Compare, then decide on the MES connection.

Common follow-ups.

Can we prove the value of RTLS without a live MES connection?

Yes. Location and time alone show search time, waits and dwell. Add the job link during the pilot.

What does the MES link add?

Which job is on each carrier, so waits become job-level.

Do we need IT involved from day one?

For the network and hosting, yes. The MES connector can come later.
