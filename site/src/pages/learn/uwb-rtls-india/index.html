Seven questions to ask

  1. What accuracy, measured how? Ask for typical accuracy and the conditions behind it, then measure it in your hardest area during a pilot. A best-case number is not an acceptance plan.
  2. What do the anchors need? Power, data cabling and sync cabling change installation time and cost in a running plant. Ask which of the three each anchor needs.
  3. Where does the data live? Many plants want location data on-premise with no internet dependency. Ask whether on-premise and cloud run the same software.
  4. How does it reach MES, ERP and WMS? Ask for the interfaces, such as REST, MQTT, WebSocket and omlox, and who builds the connector.
  5. Which standards? FiRa covers UWB interoperability and omlox covers open location data. Ask whether a product follows the specification or has passed a formal certification, and read the claim as stated.
  6. Who supports it? A location system needs a survey, tuning and changes as the floor changes. Ask where the engineers are and where spares are stocked.
  7. How small can the pilot be? One bay or one line, with a baseline measured before tags go on, is usually enough to decide.

One question suppliers skip

Ask how the system knows which job is on a tagged trolley. Location alone does not show it. A good answer describes a link between carrier and job, with a start, an end and an owner. The guide to carrier-to-job links explains what to ask. Ask AmIMotion the same question.
