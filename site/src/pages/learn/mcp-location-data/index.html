AI assistants
and location data.

The short answer

Yes. AmIHub, AmIMotion’s location software, has a built-in MCP (Model Context Protocol) server, so an MCP-capable AI assistant can query live positions, zones and history from the factory floor, located down to ±10 cm in 3D. Each assistant gets its own access, every call is logged, and write actions wait for a person’s approval. AmIMotion shows this in a live demo; the production setup is confirmed for each site.

What MCP is

Model Context Protocol is an open standard that lets AI assistants call software tools and data in a consistent way. An MCP server describes the tools it offers; the assistant decides when to call them.

What people ask

  • “Which forklifts have been idle for over an hour, and where are they?”
  • “What visited Cell 7 last night?”
  • “Where is trolley 14, and which job is on it?”

Access, logs and approval

Each assistant gets its own credentials and tool scope. It reads only what you allow. Every call is logged. Actions such as drafting a work order wait for a supervisor before anything happens.

Where it runs

The MCP server runs where AmIHub runs: on a PC inside your plant, or in the cloud. On-premise, the location data does not leave the site.

Common follow-ups.

Can the assistant act on its own?

Not in the setup AmIMotion shows. Write actions wait for a person’s approval.

Which assistants work with it?

Any MCP-capable client. Each one gets its own access rights.

Is it available today?

It is built into AmIHub and shown in a live demo. The setup for your site is confirmed during scoping.
