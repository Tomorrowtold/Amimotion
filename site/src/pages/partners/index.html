For integrators. Open interfaces. One live map.

If you connect MES, ERP, WMS or AMR fleets for plants, AmIHub gives you where things are and how long they waited, over open interfaces.

System integrators can build on AmIHub, AmIMotion's software. AmIHub serves positions, zone events and history over REST, MQTT, WebSocket and an omlox hub interface, and has an MCP server built in for AI assistants. Positions are ±10 cm in 3D with AmIMo anchors, typical and site-dependent. It can run on an industrial PC inside the plant, with no internet needed. Every interface runs over TLS, with API keys and access by role.

What you can build on.

  • Open interfaces.

    Queries over REST, zone events over MQTT, live positions over WebSocket. For developers.

  • Links to jobs.

    Send the link between a trolley and its job from the plant's own system. The MES stays in charge of the job. Which job is on the trolley?

  • One map for many fleets.

    Built on the FiRa and omlox specifications, with an omlox hub interface for data that is not tied to one vendor's format. What is omlox?

On a project.

The anchor plan for each site comes from a site survey. The architecture for the site comes with the datasheets, under NDA. How to buy.

Most projects start the way a plant pilot does: one bay or one line, one flow, a baseline agreed first. Your system keeps its job. AmIHub adds where each trolley, tool or robot is and how long it waited, and sends that to the system you already run. How a pilot runs.

Data stays where the plant chooses. AmIHub can run on site, and every interface uses TLS, API keys and access by role. Trust and data.
