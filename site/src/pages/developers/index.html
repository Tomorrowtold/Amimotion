AmIHub keeps one record of where things are and when they moved. Your systems read it over open interfaces. Nothing you build is tied to one vendor.

AmIHub exposes location data over REST, MQTT, WebSocket, an omlox hub interface and a built-in MCP server for AI assistants. Access uses API keys and role-based permissions over TLS, and every call is written to an audit log.

Questions teams ask first.

Does AmIHub have an API?

Yes. REST for queries, MQTT and WebSocket for live events and positions, an omlox hub interface, and a built-in MCP server for AI assistants.

Can AmIHub send zone events to our MES?

Yes, over MQTT or REST. Which fields and topics your MES receives is agreed during scoping.

Where is the API reference?

It comes with the detailed pack, shared under NDA before a pilot. Ask on a call.

Does it work without internet?

Yes. On-premise, AmIHub runs on an industrial PC in your plant and every interface stays on your network.
