Ask your floor a question. The live map answers.

Ask in plain words. An AI assistant answers from AmIHub's live map. Asking changes nothing.

AmIHub, AmIMotion's software, has an MCP server built in. MCP is an open standard that lets AI assistants use other software. Any assistant that supports MCP can ask AmIHub where tagged work is and how long it has waited, and answer from the live map. Asking changes nothing. Any change needs a person's approval. Every request is logged. We show it live on a call.

Today, and with AmIMotion.

  • Today.

    Questions travel one radio call at a time. Where is it? How long has it sat there? Someone goes to look, and the answer is old when it arrives.

  • With AmIMotion.

    A supervisor asks: which trolleys have waited at inspection for more than an hour? The assistant reads AmIHub's live map and answers with those trolleys.

Questions it can answer from the map.

Each answer comes from what AmIHub already holds: live positions, zones, waits and history.

  • Which trolleys have waited at inspection for more than an hour?

    AmIHub answers from its zones and the wait of each tagged trolley.

  • Where was the gauge cart last seen?

    AmIHub answers from live location, with the time it was last seen.

  • What came through the dock door this morning?

    AmIHub answers from the zone entries in that time window.

Asking changes nothing. Acting needs a person.

  • Its own access.

    Each assistant gets its own access to AmIHub: read-only, or only the actions you allow.

  • A person approves.

    Any change, such as raising a work order in AmIHub, needs a person's approval. You can require it from a supervisor.

  • Every request logged.

    AmIHub logs every request an assistant makes: who asked, what was called and what changed.

It can stay inside your plant.

The MCP server is part of AmIHub, so it can run on a PC inside your plant. If the assistant runs inside your network too, nothing has to leave it.

The same tools are open over REST and MQTT, so your own software can ask the same questions.

Common questions.

Can AI assistants query factory location data through MCP?

Yes, with AmIMotion. AmIHub has an MCP server built in, so any assistant that supports MCP can read live positions, zones and waits. Asking changes nothing. Any change needs a person's approval, and every request is logged. We show it live on a call. MCP and location data.

What is MCP?

Model Context Protocol, an open standard that lets AI assistants use other software. AmIHub has an MCP server built in.

Can the assistant act on its own?

Not without a person. Any change, such as raising a work order in AmIHub, needs a person's approval. You can require it from a supervisor.

Which assistants work with it?

Any assistant that supports MCP. Each one gets its own access to AmIHub.

Does our data leave the plant?

It does not have to. AmIHub can run inside your plant. If the assistant runs inside your network too, nothing has to leave it.
