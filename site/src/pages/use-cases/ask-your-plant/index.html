Common questions.

What is MCP?

Model Context Protocol: an open standard that lets AI assistants use software tools. AmIHub has an MCP server built in.

Can the assistant act on its own?

Not in the setup we show. It reads only what you allow, and write actions wait for a person’s approval.

Which assistants work with it?

Any MCP-capable client. Each assistant gets its own access rights.
